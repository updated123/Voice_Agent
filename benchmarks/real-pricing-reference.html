Real vendor pricing & latency reference — voice agent stack

Every figure below — cost and latency — is a number pulled from a vendor's page, a vendor's own docs/benchmarks, or an independent benchmark, with the source linked on each row. Nothing is derived from a formula or an assumed unit cost/latency. Cross-check the linked source before relying on any number here for a real budget or SLA: provider figures change often, and several rows are from third-party trackers rather than the vendor's own page (flagged where that's the case).

Compiled July 2026
Read before using these numbers. A few of these rates (marked secondary source) come from pricing-aggregator blogs, not the vendor's own pricing page — used only where an official page didn't surface a clear number in search (e.g. India telephony per-minute rates). Treat those as directional, not contractual.

Latency numbers are the messiest data to source honestly. Vendors report best-case internal numbers (often model-inference-only, or "time to first byte" including non-audio container headers); independent benchmarks measuring real end-to-end delivery are consistently 2–4x higher and vary by provider region and account tier. Both are shown below, labeled, rather than picking one.
