Voice agent cost & latency rack

Every option below is a real vendor rate or a real license (see real-pricing-reference.html for every source link). Nothing is derived from an invented "quality" adjustment — where converting a real per-token/per-character rate into a per-call cost requires an assumption (tokens/turn, chars/turn, turns/call), that assumption is an explicit slider you control, never hidden in the math.

What changed from the first version of this tool: the earlier build had per-module "escalation rate delta" values (e.g. "better denoiser → −3% escalation") — those were reasoned estimates, not sourced facts, so they've been removed. Escalation rate is now a single plain slider you set directly. Latency is shown only where a real benchmark was found; unbenchmarked combinations read n/a rather than a guessed number.
